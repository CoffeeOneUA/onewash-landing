# One Wash — Landing Page

Односторінковий промо-сайт автомийки **One Wash** (Тернопіль, вул. Протасевича 11А).

- `index.html` — готовий до деплою статичний файл (шрифти, лого, фото вбудовані як `data:` URI, зовнішніх запитів не робить).
- `template.html` — вихідний шаблон з плейсхолдерами `__OSWALD_B64__`, `__GOLOS_B64__`, `__LOGO_B64__`, `__CAR1_B64__`, `__CAR2_B64__`, `__CAR3_B64__`.
- `build.js` — Node-скрипт, який підставляє base64-дані у плейсхолдери й генерує `index.html`.

## Перезбірка

Якщо потрібно оновити шрифти/лого/фото:

1. Поклади нові файли в теку, шляхи до якої вказані на початку `build.js` (`tempDir`).
2. Онови самі base64-файли (`oswald.b64`, `golos.b64`, `logo_transparent.b64`, `car1.b64`, `car2.b64`, `car3.b64`).
3. Запусти:
   ```bash
   node build.js
   ```
   Це перезапише `index.html`.

## Деплой на Vercel

Сайт повністю статичний — окремого білду не потребує.

1. Імпортуй цей репозиторій у Vercel.
2. Framework Preset: **Other**.
3. Build Command: залиш порожнім (або `node build.js`, якщо хочеш перегенеровувати `index.html` під час білду).
4. Output Directory: `.` (корінь репозиторію) — Vercel віддасть `index.html` як головну сторінку.

## Дані

Ціни та додаткові послуги на сторінці — реальні дані з таблиць `wash_prices` та `extra_services` бази Supabase проєкту One Wash (станом на дату останньої збірки). Онлайн-оплата (WayForPay) на сайті поки не підключена — кнопка "Записатись онлайн" формує заявку і пропонує зв'язатись телефоном/SMS/Instagram.
